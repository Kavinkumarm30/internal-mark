# SRMVEC Internal Mark Calculator

A responsive web application to calculate internal marks for SRMVEC students based on CAT-1, CAT-2, and assignment scores.

## Live Demo
[https://Kavinkumarm30.github.io/internal-mark/](https://Kavinkumarm30.github.io/internal-mark/)

## Features
- **Role Selection**: Dedicated views for Students and Staff.
- **Accurate Calculation**: Follows the specific university formula for internal mark computation.
- **Form Validation**: Prevents invalid input ranges.
- **Responsive Design**: optimized for mobile and desktop.
- **PWA Ready**: Can be installed as a web app.

## Usage
1. Enter your CAT-1 exam mark (out of 100) and Assignment mark (out of 40).
2. Enter your CAT-2 exam mark (out of 100) and Assignment mark (out of 40).
3. Click "Calculate Total" to get your final internal mark out of 40.

## Staff Features
- Save student records locally.
- Export/Import student data as CSV.
